# Presença Digital para Psicologia

Recursos públicos sobre sites, SEO, mensuração e presença digital para psicólogos e clínicas.

Este repositório é mantido por **Willian Rosa** e existe como material de referência prática. O foco é melhorar descoberta, clareza, confiança e mensuração sem promessas de ranking ou de resultado clínico.

## Princípios
1. conteúdo útil antes de volume;
2. páginas específicas para intenções reais;
3. dados e mensuração para decidir o que evoluir;
4. sem promessa artificial de primeira posição;
5. comunicação profissional e revisão humana em temas sensíveis.
